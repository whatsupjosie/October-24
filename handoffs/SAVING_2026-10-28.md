# Saving across PubCast, 2026-10-28, Claude

## Reason

Josie, 2026-10-28, asked for progress to be saveable everywhere:

- Foresight
- PubCast / Bella Faux Pas
- 2i: doc files, editing sessions and text sessions
- Bella Faux Pas and PubPartner: conversations, collaborations, new cartridges and avatars

This ledger is filled in step by step as each part lands.

## What already saved on the host before this work

These were found by reading the routes, and they are the stores this work builds on:

- **2i documents:** `PUT /api/writers-room/documents/{id}`, kept in sqlite with a revision per save and per owner.
- **Foresight workspace files:** `/api/foresight/workspace/file`.
- **PubPartner:** sessions and turns.
- **Conversations and messages:** the conversation archive, chat rooms and DMs.
- **Avatar library:** `/api/avatars/imports`.

These were browser-only:

- the Counter layout (`foresight.counter.v3:<owner>`)
- the studio's tuning

These were missing:

- studio progress
- cartridge creation
- avatar creation from PubPartner

### A bug found on the way: none of PubPartner's menus could be seen or clicked

The top bar's notched shape is a CSS `clip-path`, and that also clips the drop-down menus hanging below the bar. File, Edit, View, Media, Tools, Wardrobe, Memory and Settings all "opened", but nothing showed and the desk took every click. Every menu command was unreachable by mouse.

The fix leaves the bar's design untouched. While a menu is open, its drop-down is shown outside the bar (`position: fixed`, under its button) with the same look, and it is put back when it closes (`floatMenu` and `closeMenus` in `pubpartner.js`).

`tests/test_pubpartner_menus_browser.py` opens all eight menus at 1440×1000 and 1280×800. It checks that every item is the topmost thing at its centre and inside the window, that Escape puts the menu back, and that a real click runs an item. It passes now and fails on the old code.

## Untested

- Cartridges in the Bella Faux Pas Studio. The studio wears library avatars per character (pete, RePete, Sir Purfluous); a PubPartner cartridge is not a walkable character there yet.

- Windows / PowerShell 5.
- Two devices editing the same owner's progress or layout at once. The store refuses a stale writer only when it sends `expected_revision`; the walker sends none, so the last save wins.
