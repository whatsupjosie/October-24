# PubCast Reach — World Chat + 2i Collab integration checkpoint

## Scope, 2026-09-23
Source: user's 15,711,350-byte PubCast_Reach_FORESIGHT_FRONT_DOOR_PASS2_09-15-2026(2).zip. All modifications were made to an isolated working copy. Original source ZIP and connected repositories were not changed.

## Implemented
- Foresight's permanent World Chat blade launches `/static/world_chat.html`, not an archived one-person conversation named World Chat. Sibling `+ new chat` blades keep the existing Conversation Ownership/Save All Raw/ZIP routes.
- The shared World Chat surface reads and writes the existing PubCast `world` room (`GET /api/chat/rooms/world`, `POST /api/chat/rooms/world/send`); both Foresight and 2i use the same client component. Message text is rendered with `textContent`; caller-supplied `user`, `user_id`, and `role` are ignored on send. Public World Chat is a room transcript, not a personal AI session.
- 2i adds an optional collapsible World Chat panel beside, not instead of, its existing PubPartner chat. Phone layout moves that same World Chat element into the Partner view, retaining manuscript and private partner conversation state.
- World Chat first loads existing append-only `world.jsonl` history, receives authenticated room WebSocket notifications, and retains a two-second REST refresh fallback. The UI displays up to 100 most recent messages, while `Save full room log` downloads the complete role-authorized JSONL transcript. Export never serves DMs. Hub now reads only the bounded log tail for recent-history queries.
- `/ws/chat/{room_id}` now resolves and verifies its own token (FastAPI HTTP Depends never resolved identity for WebSocket), blocks unauthorized access when `PUBCAST_ENFORCE_AUTH=1`, binds sender exclusively to the verified token, and accepts chat-only payloads. The old generic `/ws/world` and `/ws/dm____*` ingress is blocked to prevent bypassing the dedicated room/DM guards. Development mode remains explicitly unauthenticated; use `run_reach.py` or `PUBCAST_ENFORCE_AUTH=1` for the real identity boundary.
- Existing Hub append-only message log remains the room authority. Hub message paths also forward facts to the offline BlackBox witness; `chat.message` now maps to a distinct `CHT` chat transcript / `MSG` message-persisted record (not the old unknown-event `ERR`). The witness retains actor, room, exact text and time; if witness write fails, Hub logs a warning and keeps its primary room log. No guest-facing BlackBox UI was added.
- 2i keeps manuscript/Collab authority. `toggleMode` now refuses to leave Collab when a nonempty pencil draft is uncommitted instead of calling `approveBuffer()` automatically. Explicit Commit draft triggers a short visual ghost of the handwritten text moving upward over the seam and resolving toward the typeset area; reduced-motion settings skip this animation. Core committed/buffer state and existing autosave/recovery and private PubPartner paths stay independent from the new room.

## Remaining gates / no false claims
- The World room is connected to the existing Hub/BotManager, but this change does NOT rewrite existing AI bot-provider responses through the newer PubPartner neutralizer/personality pipeline. That AI character integration must be verified separately, with explicit character scope and agency controls.
- This checkpoint did not implement full 2i multiplayer manuscript synchronization, a World Chat word processor, STT/TTS controls inside World Chat, or finished owner/system/private-Cricket channels. It did not test microphone permissions, real multi-guest deployment, actual model-provider replies, cross-process room fan-out, or production browser rendering.
- Log export is JSONL, not BlackBox export. Room transcript is accessible to each authenticated participant authorized for that room; private manuscripts and PubPartner archives are separate and not exported with it.
- Before deployment: run the local build with enforced authentication, test two real browsers (Foresight + 2i, phone + desktop), check Visual Commit and save/reload behavior, and reconcile the unrelated full-suite failures without weakening old tests.
